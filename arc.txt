Воронка (конверсии)
Метрика	Формула
CTR	clicks / impressions * 100
CR клик → лид	leads / clicks * 100
CR лид → MQL	mql / leads * 100
CR MQL → SQL	sql / mql * 100
CR SQL → встреча	meetings / sql * 100
CR встреча → КП	offers / meetings * 100
CR КП → сделка	deals / offers * 100
Общая конверсия	deals / clicks * 100
Стоимости
Метрика	Формула
CPC	adBudget / clicks
CPM	adBudget / impressions * 1000
CPL	marketingCosts / leads
CPQL	marketingCosts / mql
CPSQL	marketingCosts / sql
CAC	marketingCosts / deals
CPA	marketingCosts / deals
CPO	marketingCosts / offers
ROI / ROMI / ROAS
Метрика	Формула
ROMI	(revenue - marketingCosts) / marketingCosts * 100
ROI	(grossProfit - marketingCosts) / marketingCosts * 100
ROAS	revenue / adBudget
ROAS (полный)	revenue / marketingCosts
Доля маркетинга	marketingCosts / revenue * 100
ACV (Average Customer Value)	avgRevenuePerClient
LTV / CAC
Метрика	Формула
LTV	avgCheck * avgPurchaseFreq * avgLifetimeMonths * avgGrossMargin
LTV / CAC	ltv / cac
Payback period	cac / (avgCheck * avgGrossMargin)
Эффективность
Метрика	Формула
AOV (Average Order Value)	revenue / deals
AOV (средний чек)	avgCheck
Retention	repeatClients / activeClients * 100
Churn	100 - retention
Bounce rate	bounces / totalVisits * 100
ОР (органика)	organicVisits / totalVisits * 100
Доля рынка	som / tam * 100
Доля SAM	som / sam * 100
Юнит-экономика
Метрика	Формула
Маржа с клиента	avgCheck * avgGrossMargin
Прибыль с клиента	(avgCheck * avgGrossMargin) - cac
Точка окупаемости	cac / (avgCheck * avgGrossMargin)
Выручка на клиента	avgRevenuePerClient
Прибыль на клиента	revenue - marketingCosts
